# Games Center Perú — Tienda web de videojuegos

Proyecto web de aprendizaje que presenta un catálogo y páginas de una tienda de videojuegos. El repositorio contiene páginas HTML estáticas con estilos y recursos visuales propios del proyecto.

## Páginas identificadas

| Página | Propósito |
| --- | --- |
| [Inicio](index.html) | Presentación principal |
| [Productos](productos.html) | Vista de productos |
| [Detalle de producto](detalle-producto.html) | Información de producto |
| [Nosotros](nosotros.html) | Presentación del proyecto |
| [Contacto](contacto.html) | Página de contacto |
| [Registro e inicio de sesión](registro-login.html) | Interfaz de acceso y registro |

> **Estado:** proyecto de aprendizaje. La presencia de formularios o pantallas de acceso no demuestra por sí sola la existencia de un backend, pagos reales, almacenamiento de contraseñas ni seguridad de producción.

## Tecnologías observadas

- HTML y CSS.
- Bootstrap y recursos estáticos, según las referencias del archivo `index.html`.
- JavaScript u otros recursos adicionales pueden estar presentes; consulta el código antes de asumir funciones.

## Ejecución local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/EdhuMS/ProyectoWeb-TiendaDeJuegos.git
   cd ProyectoWeb-TiendaDeJuegos
   ```
2. Abre `index.html` con un navegador. Si alguna característica depende de solicitudes HTTP, utiliza un servidor local como `python -m http.server 8000` y visita `http://localhost:8000`.

No se ha verificado una infraestructura de comercio electrónico lista para operar con clientes.
